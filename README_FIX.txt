A2 = مقدم + إجابات كتابية.
A3 = لاعبين فقط.
الكود يحدد النمط تلقائياً: A1xx / A2xx / A3xx.
شاشة العرض متاحة لـ A1 وA2 فقط.
تمت إزالة زر Buzz الأحمر الكبير واستبداله بأزرار صغيرة.
تمت إضافة تصفير Strikes للمقدم.
تمت إضافة حفظ جلسة اللاعب وإعادة الاتصال بنفس المقعد والنقاط.

مجلد مستقل public/games/guess/ مع واجهة مستقلة للعب.
