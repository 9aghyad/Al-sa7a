# Stage 20 — Smart Room Entry

- QR/share links now use `/player?code=...` and the player route inspects the room before joining.
- Saved sessions are routed directly to the correct game page with the existing session token.
- The shared join screen pre-fills the saved profile name.
- Family Feud, Bomb, and Faceoff show team selection on the shared join screen.
- Join links no longer require the player to manually identify the game.
- Existing room/session/reconnect systems remain in place.
