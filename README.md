# المفخخة — v5

## تحديثات هذا الإصدار
- في أنماط اللاعبين الكتابية لا يوجد عدّاد 10 ثوانٍ قبل الإجابة؛ **الـ10 ثوانٍ هي وقت الإجابة نفسه**.
- عدّاد الإجابة مرتبط بفتيل بصري مشتعل ومؤثرات توتر/نبض وصوت Tick.
- الدور بالتناوب بين الأحمر والأزرق ويبدأ تلقائيًا عند وجود لاعب متصل في كل فريق.
- لا يوجد زر بدء في الأنماط الكتابية 2 و3.
- التصحيح الكتابي يطابق الإجابات الموجودة بالقائمة تلقائيًا، ويدعم الإجابة الصحيحة خارج القائمة بنقاط أقل، والخطأ بخصم نقاط وStrike.
- كشف الإجابة يتم بعد مرحلة تشويق؛ المربع يبقى مخفيًا أثناء لحظة الحقيقة ثم ينقلب ويظهر محتواه.
- القنبلة تعرض خصمًا قويًا وتأثير انفجار، والإجابة الآمنة تعرض المكافأة.
- واجهتا إنشاء الغرفة والانضمام إلى الغرفة تستخدمان نفس الهوية البصرية للمفخخة.
- Family Feud لم يتم تغيير نظامه.


## إصلاحات v5.1
- إصلاح اختيار أنماط المفخخة الثلاثة: كانت أزرار النمط تستدعي `bombM()` غير الموجودة، لذلك كان النمط يبقى `1` دائمًا.
- نمطا الشاشة + اللاعبين واللاعبين فقط يبدأان تلقائيًا بعد وجود لاعب متصل في كل فريق.
- المفخخة أصبحت نمط لاعبين فقط: فريقان، بدء يدوي من صاحب الغرفة، تصحيح كتابي تلقائي، وكشف إجابات بتشويق ومفخخات.
- إصلاح انتقال النمط الأول بين الجولات بحيث يعود إلى مرحلة BUZZ بدل إعطاء لاعب الإجابة مباشرة.
- منع فتح شاشة عرض في نمط اللاعبين فقط.

## Mofakha v7 fixes
- Mode 1 creates the room as the presenter/host, not as a player.
- Mode 2/3 create the room as the first player.
- Direct navigation to the bomb player page avoids the old join-page handshake race.
- Bomb timeout now applies a -20 point penalty and one strike in every mode, including presenter mode, then advances the turn.
- Timeout result is shown explicitly instead of appearing as a silent no-op.
- Duplicate submit is blocked client-side after sending.


## Mofakha v11
- Question stage shows counts only; answer texts stay hidden.
- Bomb answers are single-word entries.
- Answer submission uses socket acknowledgement and retry while time remains.
- Click sound is disabled inside the Bomb gameplay screen.


## Mofakha v14
- الأسئلة أصبحت سهلة ومباشرة: اذكر دولة بحرف، اسم بحرف، حيوان، فاكهة، أشياء يومية، إلخ.
- كل سؤال يحتوي 6 بطاقات إجابة، وتبدأ الجولة الأولى بمفخخة واحدة ثم ترتفع المفخخات تدريجيًا حتى 3.
- إضافة زر «كشف الإجابة» لكل بطاقة مخفية.
- إضافة «تبديل السؤال» في اللعب لتجنب التعلق بسؤال غير مناسب.
- إصلاح تدفق المفخخة بالكامل: زر الاستعداد، طور الإجابة، والإرسال الكتابي مع ACK وإعادة محاولة آمنة.
- صفحات `/games/bomb/*` أصبحت تستخدم الصفحة الموحدة بدل ملفات غير موجودة.
- إضافة `/health` كمسار فحص صحة لـ Render وتثبيت حد Node 20+.


## Mofakha v15 — سوق وخمنها
- السوق: الإجابة أصبحت **شفهية بالكامل**؛ لا يوجد حقل كتابة ولا كيبورد ولا عداد 5 ثوانٍ للإجابة.
- بعد الـBuzz ينتقل الدور مباشرة إلى تصويت بقية اللاعبين، مع استثناء صاحب الإجابة من التصويت.
- البز العادي والبز الدبل فقط، والدبل يرسل تأثير برق/رعد مرئيًا للجميع مع صوت واهتزاز.
- تسلسل الجولة: السؤال → إظهار النقاط → 3،2،1 → فتح البز.
- نتائج التصويت: الأغلبية نعم = نقاط الجولة، الأغلبية لا = خصم نقاط الجولة، التعادل = لا تغيير. الدبل يضاعف قيمة الجولة.
- تصميم السوق محدّث ليتبع المرجع المرسل: مسرح/ملعب أزرق، أزرار Buzz كبيرة، زر Double بنفسجي، وبطاقة ترتيب اللاعبين.
- خمنها: بطاقات الكلمات المكشوفة تعرض اسم الكلمة مع صورة/معاينة بصرية، وزر كشف الكلمة يتحول إلى إغلاق وإخفاء بدون نافذة تأكيد.
