# لعبة العائلة — Player Only

نسخة Family Feud بشاشة واحدة لكل لاعب، بدون مقدم وبدون شاشة عرض منفصلة.

- كل اللاعبين يدخلون من `/player` أو من الرابط الرئيسي.
- أول لاعب ينشئ الغرفة ويحدد الجولات وأسماء الفريقين.
- أي لاعب يستطيع بدء السؤال، كشف الإجابات، احتساب النقاط، تسجيل Strike والانتقال للسؤال التالي.
- نفس بنك الأسئلة الكبير الموجود في النسخة الأصلية.
- Render Web Service: `npm install` ثم `npm start`.
- لا تستخدم Static Site.


## تحديث v4
- تصميم شاشة لعب عريضة بأسلوب شاشة العرض، بدون مقدم أو شاشة منفصلة.
- زر «أجاوب كتابيًا» لمدة 10 ثوانٍ.
- زر «⚡ دبل + إجابة» يبدأ إجابة كتابية لمدة 10 ثوانٍ ويضاعف نقاط الإجابة، ويُستخدم مرة واحدة لكل فريق في اللعبة.
- السؤال التالي أصبح عشوائيًا دائمًا.
