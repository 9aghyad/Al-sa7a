# المفخخة — v5

## تحديثات هذا الإصدار
- في أنماط اللاعبين الكتابية لا يوجد عدّاد 10 ثوانٍ قبل الإجابة؛ **الـ10 ثوانٍ هي وقت الإجابة نفسه**.
- عدّاد الإجابة مرتبط بفتيل بصري مشتعل ومؤثرات توتر/نبض وصوت Tick.
- الدور بالتناوب بين الأحمر والأزرق ويبدأ تلقائيًا عند وجود لاعب متصل في كل فريق.
- لا يوجد زر بدء في الأنماط الكتابية 2 و3.
- التصحيح الكتابي يطابق الإجابات الموجودة بالقائمة تلقائيًا، ويدعم الإجابة الصحيحة خارج القائمة بنقاط أقل، والخطأ بخصم نقاط وStrike.
- كشف الإجابة يتم بعد مرحلة تشويق؛ المربع يبقى مخفيًا أثناء لحظة الحقيقة ثم ينقلب ويظهر محتواه.
- القنبلة تعرض خصمًا قويًا وتأثير انفجار، والإجابة الآمنة تعرض المكافأة.
- واجهتا إنشاء الغرفة والانضمام إلى الغرفة تستخدمان نفس الهوية البصرية للمفخخة.
- Family Feud لم يتم تغيير نظامه.
